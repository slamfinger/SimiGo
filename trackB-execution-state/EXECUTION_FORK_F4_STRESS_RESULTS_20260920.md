## 决策

1. **F4-A/B/C 全过,B branching execution state 在本机边界内
   (≤128K 单层、≤16 活跃分支、≤16 级链)无结构性失败。**
   逻辑主干迁移 = O(1) 引用切换且零拷贝;与物理内存所有权分离
   (旧主干缓冲作为历史驻留,Discard 负责回收)——复盘要求的
   "两者分别测量"已分别入表。
2. **回归项(F3a 规则触发记录,不阻断)**:单层多段 concat decode 税
   1.90×(@18.4K/4 段,上界口径)。**未测缺口:模型级长深度 + 多段链
   的 decode 税**(此前模型级仅 4.2K 单段 1.01×)。列为 F4 续项第一
   优先——若模型级 >1.10×,激活专门消解(视图缓存/段合并)。
3. **⚠ 归因项**:Discard 单点 active 不降(F4-B)vs 同机制可降
   (F4-C)——怀疑 MLX 惰性图已 eval 节点的父引用保留;需一次
   Instruments/allocator 级归因,不阻塞主线。
4. **F4-D(上游 RFC)**:素材已足(段表语义/多级 fork/页恢复/解冻
   续写门/四指标数据),待整理为 F0 上游草案升级版;表述纪律——
   本地原型段表 ≠ 官方 paged KV 能力,对齐 #1849 的 hooks 提案语言。
