| 因子 | cag(H=8,V0) | lfu_aging |

**待检验机制假设(预注册,不作断言)**:
- **H-S1(tie 层信息丢失)**:tree 为 8 链游走相关访问,窗口计数
  弥散 → 零分/饱和层大 → id tie-break 丢弃 recency 信号(F3 主导);
- **H-S2(饱和粒度)**:`min(1,n/H)` 把"较热"与"已饱和"压成同分,
  计数排序信息被截断(F1 主导;H=4 更差与此相容但不证明);
- **H-S3(底座失配)**:窗口计数 vs 老化累计对游走型访问的适配差

**可观测问题 = 解释 +70.5 J(tree)的单因子归因**;若无一因子可
归因,则"引入非饱和形态"无可观测问题支撑,V0 形态保留并记录阴性。

## 2. 变体冻结定义(三因子消融;全部 frequency-only 家族)

统一冻结:B=12、seed=42、同 trace(hot/tree)、C_ext=0.69/C_rehy=
0.72、argmin Score、NORM①②③、驱逐 key 均为 (Score, …, id) 收尾。

| 变体 | F1 分数 | F2 底座 | F3 tie | 隔离目标 |
|---|---|---|---|---|
| **V0** = cag(H=8) 现行 | min(1,n/H) | window 200 | id | 基准(=v2 冻结数字) |
| **V1** | min(1,n/H) | window 200 | **last_access** | F3 单独 |
| **V2** | **n/(n+H)** | window 200 | id | F1 单独(tie 与 V0 同) |
| **V3** | n/(n+H) | window 200 | last_access | F1×F3(V1 上换形态) |

递增、无新超参数、不引入 log 底数自由度;H 语义从 saturation
scale 改称 **half-saturation scale**(n=H 时分数=1/2),延续 v0.2.1

H∈{4,16} sensitivity(V1 分数与 V0 同,复用 V0 已有敏感性;V4 无 H)。

### 2.1 形态决策与参数调优分离(S_cont 拟合空间钉死,v0.2)

S_cont 并非"自然正确"的唯一连续替代——它改变的是**频率差异映射到
驱逐分数的曲率**。因此本轮把以下五条钉死为设计约束:

1. **H 语义三层禁令**:H 不是 prediction horizon、不是未来窗口
   (v0.2.1 已钉),本轮进一步——H **仅为 half-saturation scale**
   (S_cont(n=H)=1/2),无任何时间/预测语义;
2. **同一性约束**:S_cont 与 min(1,n/H) 使用**同一 n**(同窗口计
   数实现)、**同一 W=200**、**同一 key 结构与 tie 规则**;变体间
   唯一差异 = 分数函数本身,不得夹带其他改动;
3. **函数形式封闭**:S_cont=n/(n+H) 经审核确认即封闭;**禁止按
   实验结果调整函数形式**(换 log/幂/分段/混合等),禁止赛后引入
   第二连续形态比较——本轮不搜索"最佳函数";
4. **本轮问题重申**:只回答"**这个预注册形态是否产生可观测差异**"
   及其单因子归因,不回答"哪个函数形式最优";
5. **采纳后纪律**:若 R2/R5 采纳 S_cont 为 v0.3 候选,后续任何函数
   形式变更同样走 design correction + 审核,不得在结果文档内直接
   换形。

### 2.2 V4 定位 = 底座控制组,非对称候选(v0.2)

V4(windowed-LFU)**不是与 V0–V3 对称的"第五个候选形态"**,而是
F2(计数底座)的**控制组**,使底座因子可读:

- **合法读数仅两个差分**:V4−V3(有界→无界:F1 在 recency tie 下
  的效应)与 V4 vs lfu_aging(窗口 vs 累计+半衰:F2 主读数);
- **禁止**"V0–V4 五策略 J 排序谁更低"式解读;V4 单独对 V0–V3 的
  J 比较无结论资格(其分数/底座/tie 与 V0–V3 均不同时不同);
- 结果呈现分区:V0–V3 = 消融组,lfu_aging/V4 = 参照与控制组,
  表格物理分开,防误读。

### 3.1 机制观测通道(v0.3 重构;五通道封顶,职责钉死)

**实现方式(先钉,防歧义)**:F3/F1 通道 = **V0 轨迹内单跑反事实
instrumentation**——在 V0 的每次驱逐事件上,对实际候选集同时计算
"若 tie-break / 分数规则不同,此刻会选谁"。不跨跑逐事件对齐:两跑
状态在首个分歧驱逐后即分叉,跨跑"同一事件位置、同一候选集"无定义
(v0.2 审核意见的表述按此方式形式化)。F2 通道 = 合法对(V4 vs
lfu_aging)两独立跑的驱逐序列按事件序号对齐比较。**全部通道只观测,
不入 J,不改任何策略行为。**

| 通道 | 回答什么 | 归因资格 |
|---|---|---|
| `tie_rate` | tie 触发环境多频繁? | **仅辅助,禁止用于归因**——相同状态下 tie 集合由 Score 唯一决定,与 tie-break 规则无关 |
| `tie_resolution_disagreement_rate`(F3 核心) | tie 发生后,换 tie-break 规则是否真改选择? | F3 归因证据 |
| `sat_collision_flip_rate`(F1 核心) | 饱和压平是否在真实决策点改变选择? | F1 归因证据 |
| `eviction_agreement_rate` + 首分歧位(F2 核心;仅 V4↔lfu_aging 合法对) | 换计数底座是否真改驱逐序列? | F2 归因证据 |
| J(既有五通道照旧) | 行为结果是否闭合? | 必要,单独不充分 |

**定义**:

1. `tie_rate`:驱逐事件中 argmin Score 并列(≥2 候选)占比;各
   变体自报,纯描述。
2. `tie_resolution_disagreement_rate`:V0 轨迹的 argmin tie 事件
   中,V0 实选(最低 id)≠ 同一候选集内 last_access 规则所选
   (key 中 last_access 最小者,即最早访问)的事件占比;附 flip
   事件绝对计数。
3. `sat_collision_flip_rate`:**sat_collision 事件 = V0 驱逐事件中
   全体候选均饱和(n≥H,Score≡1)**(部分饱和事件可证两规则同选:
   未饱和候选分数必低且计数更小,两函数 argmin 一致——公式层推论,
   只作披露非证据);flip = 该事件上 S_cont(同 id tie)反事实改选
   (= 最低 id 候选 ≠ 最小 n 候选);rate = flip 数 / sat_collision
   事件数,附两者绝对计数。对照示例(V0:n=8,9,12,20 全压平为 1,
   排序丢失;S_cont 下 8/9/12/20 严格保序)即本通道的机制图像。
4. `eviction_agreement_rate`:V4 与 lfu_aging 驱逐序列按第 k 次驱逐
   事件对齐,同 victim 事件占比;附首分歧事件序号。
5. **行为一致性下界(通用核对式,防实现/定义错误)**:任意变体对,
   驱逐选择不一致事件数 ≥ |Δrehy|(每对 rehy 差额至少对应一次不同
   驱逐决策);通道计数低于该下界 → 先查实现,不得进入判读。

注:全体饱和事件同时必为 tie 事件,F1/F3 通道可在同一事件上非零
——归因判定以"变体级 J + 各自核心通道"组合为准,交互情形由 R5
覆盖,不新增指标。

## 4. 判读规则(预注册;描述性;单 seed 限定)

- **归因三条件(v0.2 升格;全部满足才可归因,缺一不可)**:
  1. **差距闭合**:候选因子变体在目标 workload(tree)上的 J 改善
     ≥ 该 workload V0→lfu_aging 差距的 **50%**(tree ≥35.3 J;
     hot 参照线 ≥1.5 J);
  2. **机制同向(v0.3 按通道职责重写;tie_rate 条款废除)**:对应
     因子核心通道非零且过行为一致性下界——F3 须
     `tie_resolution_disagreement_events ≥ |rehy(V1)−rehy(V0)|`;
     F1 须 `sat_collision_flip_events ≥ |rehy(V2)−rehy(V0)|`;
     F2 须对齐序列不一致事件数 ≥ `|rehy(V4)−rehy(lfu_aging)|`;
  3. **无反向证据**:另一 workload 无超阈值恶化(hot 恶化 >5.8 J
     = 现 hot 族内差距 2.9 J 的 2 倍,即视为反向),且无其他通道
     异常。
  三个阈值均为**描述性约定**(单 seed 合成 trace,非统计检验),
  预注册后不得赛后调整。**仅 J 接近不构成归因**——单看 J 会把
  tie-break 效应误归因为 min(1,n/H) 形态,这正是 benchmark 偶然性
  的排除条款。
- **判定顺序(v0.3.1 文字修正:原"(V4−V3)"系标注笔误;F2 操作
  定义以 §2.2/§3.1/§4-R3 为准 = V4↔lfu_aging;P3-B 判读当时即按
  操作定义执行,实验无需重跑)**:先测 F3(V1)/F1(V2)/
  F2(V4↔lfu_aging)单因子三条件 → 全不达则测复合 V3(V1×F3)→
  仍不达 → R4 阴性。
- **决策矩阵**:
  - **R1(F3 主导,三条件达成)**:min(1,n/H) 形态保留;修正属
    **策略语义**(tie-break 序),走 design correction,非形态改造;
  - **R2(F1 主导,三条件达成)**:采 S_cont 形态为 v0.3 公式候选,
    走 design correction → 审核 → 方可改 target 定义;
  - **R3(F2 主导,三条件达成)**:形态问题让位于底座选择问题,
    设计延伸一轮(窗口 vs 老化),仍不改 target;
  - **R5(复合主导,v0.2 新增;V1/V2 单因子均不达而 V3 达成)**:
    F1×F3 交互主导——"形态 + tie 语义需联合修正",R1+R2 并案单一
    design correction 提审;单独采 S_cont 或单独修 tie 均不批准;
  - **R4(V3 亦不达)**:阴性入档——**"在本实验域、预注册阈值与
    观测通道下,未获得足以支持非饱和/连续形态改造的可观测证据"**
    (仅此强度;不证负命题"非饱和形态无可观测问题",与 H-P1/
    nodes-out/真实 workload 后续发现不冲突),V0 保留,70.5 J 差距
    归档为未归因成因,H-P1 讨论另立。
- 热侧一致性检查:hot 差距仅 2.9 J,任何变体在 hot 上大变动均视为
  异常信号,先查实现再解读(与三条件之 3 联动)。
