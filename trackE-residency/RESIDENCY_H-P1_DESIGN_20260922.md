## 0. 锁定的 Design Question(①原文,不改写)

> **在既有 tree 拓扑结构(P3 冻结拓扑域)的预注册实验域内,是否存在
> 依赖该拓扑、与未来缺失成本具有预定义关系,并且能够仅由当前与
> 历史可观测状态在线计算的结构信号?**

## 1. 第一核心设计问题:L1/L2 信号形式关系

**问题**:L1 的关系检验中,信号以什么形式存在?若允许"离线诊断
形式"(用全 trace 计算信号量),则该形式与未来成本的相关可能部分
同义反复(全 trace 活跃度天然包含未来访问),L1 PASS 会被泄漏污染;
若只允许在线形式,L2 退化为构造审计,出口 B 罕见化。

**提案:O1 单形式方案(推荐)**:
- **全部预注册信号只存在在线形式**(在驱逐时刻 t,仅由 [0,t] 的
  访问与静态拓扑计算);L1 直接检验在线形式与 oracle Y 的关系;
- **L2 = 构造审计**(非数据阶段):代码级检查 + 运行时断言——信号
  计算路径只读取 [0,t] 状态与静态拓扑常量;审计失败 = 设计错误类
  L2 FAIL,如实入档(预期罕见,设计评审先行拦截);
- **出口 B 在 O1 下的语义**:保留——若实现审计发现某预注册信号的
  计算路径事实上依赖未来信息,即 B;预期不出现,出现即设计问题。

**被否决的 O2(双形式)及理由**:L1 用离线形式检验、L2 要求在线
等价——离线形式的 X 侧不可避免吸入未来访问(灰区泄漏),且"关系
保持"需要第二套判据,预注册负担与 fishing 面同时增大。与 oracle
不入信号构造的已锁边界精神冲突。

**代价如实声明**:O1 下,三可能中的"B 结构信息不可在线转化"在
H-P1 内不可正面检验(oracle 边界使其不可测),L1 FAIL 时该可能
保持 OPEN 并入档,不在本轮裁定。

## 2. 信号形式预注册(封闭;在线单形式)

窗口语义与 P3 冻结模拟器一致:W=200,visits(m,[t−200,t]) = 节点
m 在窗口内的访问次数;ancestors(n) = 同链位置 < pos(n) 的节点;
chain(n) = 同链全体 4 节点(集合定义;信号计算排除候选自身,见下)。

| 类 | 信号(在线形式) | 说明 |
|---|---|---|
| S1 | pos(n) ∈ {0,1,2,3} | 静态;子树规模 = 4−pos 仅作派生披露 |
| S2 | A_anc(n,t) = Σ_{a∈ancestors(n)} visits(a,[t−200,t]) | 祖先前缀活跃度 |
| S3 | A_chain(n,t) = Σ_{m∈chain(n), m≠n} visits(m,[t−200,t]) | 全链活跃度(self-excluded:只计同链其他节点) |

**S3 self-excluded 钉死**:S3 计算同链**其他**节点的窗口访问次数,
不包含候选节点自身的访问——`A_chain` 之名在全文档统一指此
self-excluded 定义,禁止实现出第二含义;S2 祖先集合天然不含自身
(③排除同向);执行中不得新增信号或派生来源。

## 3. L1 关系检验预注册

- **事件集**:Tier-1 冻结域(tree trace)上,**lru 与 C 两个参照
  运行的全部驱逐事件之并集,且为 (node, t) 二元组的去重集合**——
  lru/C 产生相同事件时仅保留一条观测,不因来源不同而重复加权;
  事件来源作 provenance 字段记录,不改统计权重(结构策略不参与
  事件生成——L1 独立于 L3,免循环);每事件 = (被驱逐节点 n,
  驱逐步 t);
- **oracle Y**:F(n,t) = n 在 (t, T] 的再访问次数(纯 oracle,
  只上 Y 侧);
- **统计量与存在性线**:逐类逐 workload 计算 Spearman
  ρ(S(n,t), F(n,t));**存在性线 |ρ| ≥ 0.1**(预注册常数,描述性
  约定非统计检验,house style);方向**双侧**(存在性不预设方向,
  实测方向作为机制知识报告);
- **L1 PASS** = ≥1 类在 tree 上 |ρ| ≥ 0.1(Tier-1);
- **hot = 预注册阴性对照**:hot trace 访问与拓扑无关(均匀随机),
  结构信号在 hot 上应 |ρ| ≈ 0;hot 对照**使用与 tree 相同的事件
  构造(去重并集)、统计方法与信号计算路径,逐类、逐 workload
  报告**;预注册对照界:hot 侧 **|ρ| ≥ 0.1 视为触线**,触线 = 停,
  先查实现再判读——触线只触发实现/泄漏审查,不直接证明结构信号
  存在;hot 对照是实现/泄漏哨兵,非"数学上必须为零"的统计无相关
  证明;
- **Tier-2**:逐 seed 重复同一检验(§5)。

## 4. L3 策略预注册(封闭;三形态 + 敏感方向)

统一形态:驱逐 = argmin key over candidates(NORM③),key 收尾
(last_access, id);结构信号以 keep-worthiness K 作首键。方向为
**生成器先验声明**(先验推理见括号,锁定后不得因结果改向):

| 策略 | key 首键 K(n) | 方向声明(生成器先验) |
|---|---|---|
| P_S1 | −pos(n) | 驱逐最深优先:浅层节点有更多到达路径(上行游走必经前缀) |
| P_S2 | −A_anc(n,t) | 驱逐祖先最活跃优先:祖先活跃 ⇒ 游走在节点上方已过 ⇒ 节点短期不被到达 |
| P_S3 | +A_chain(n,t) | 驱逐最冷链成员优先:活跃链 = 游走仍在本链内 ⇒ 链上节点更可能被续访 |

**自排除的链内后果(有意设计,锁定)**:K=+A_chain 因 S3 排除自身,
同链候选间比较中链和相消,驱逐序退化为**优先驱逐自身窗口访问最多
的成员**——生成器先验解读:游走刚访问 n ⇒ 短期最可能续访的是邻居
而非 n ⇒ 先驱逐 n 与"游走仍在本链"先验一致;此后果由 S3 定义唯一
确定,实现不得另用"链内最冷成员"的朴素读法。

- 每形态附**敏感方向**(符号取反)为预注册次级形态,同时运行同时
  报告;**L3 PASS 要求主方向形态达成**;仅敏感方向达成 = 记
  "PASS(敏感方向)",交审核裁定,不自动等同 PASS(防二选一 fishing);
- **L3 判据(PASS)**:主方向形态 J **< J(C)** 于 tree(Tier-1;
  确定性域内任何裕度都是真实改进,幅度如实报告);hot 侧无判据,
  仅披露(阴性对照域);
- **结构-only 为本轮封闭集**;结构+频率 hybrid 形态**不入本轮**
  (若结构-only 有任何信号,hybrid 留后续轮立项——防组合爆炸,
  列 §9 焦点供审核确认)。

## 5. Tier-2 预注册

- K = 5 个额外 seed:{43,44,45,46,47}(同生成器/拓扑/长度/
  workload);
- L1:逐 seed 全检验;**一致性判定维度 = 信号类 × tree workload
  逐项判定**(tree 是 L1 主判定 workload;hot 为独立阴性对照,不参
  与 L1 阳性判定——hot 结果不得抵消 tree 结果,tree 结果不得掩盖
  hot 触线);**一致 = 同类、同号、同 |ρ| ≥ 0.1 在 ≥4/5 seed
  成立** ⇒ 该类信号可写"生成域事实";否则"域限定";
- L3:逐 seed 描述性报告(参照 LRU/C/Belady 逐 seed 重跑,便宜且
  必要);L3 的 seed 级结论按④精度级措辞;
- 全部 Tier-2 运行在回归门之后。

## 6. 回归门与工具(simulator v6)

先于一切新策略采数:
- v6 引擎复现全部冻结参照:P3-A(lru/lfu_aging/belady/V0 主表 +
  H 敏感性 + pressure 通道)、P3-B(V0 ≡ v4 序列逐位)、P3-C
  (A ≡ V4 / C ≡ cum-nd / B ≡ window+decay);
- 结构策略无冻结参照(全新),其正确性由:引擎共享路径的回归等价 +
  确定性自检 + 行为一致性下界(dd ≥ |Δrehy|,适用于结构策略 vs
  参照行)+ hot 阴性对照共同护航;
- 机制哨兵照旧(描述性);五通道输出照旧;P_pressure 不涉。

## 7. 判读矩阵(⑤ 出口落地;逐类署名;精度级绑定)

- **A(L1 FAIL,前置 L2 PASS)**:三类均 |ρ| < 0.1(tree)。"在预注册信号集、
  实验域和判据下,未获得足以支持结构信号存在性的证据"(逐类署名 +
  精度级;hot 对照须先通过);
- **B(L2 FAIL,无论 L1 结果;L1 数据作废)**:构造审计发现未来信息
  依赖(预期不出现,出现 = 设计错误如实入档);
- **C(L1 PASS ∧ L2 PASS ∧ L3 FAIL)**:信号存在且可在线计算,
  但主方向形态未胜 C;"未验证机制候选/诊断线索"入档,不进已验证
  清单;
- **D(全过)**:结构策略成立的实验性证据(精度级 per §5);结构
  信号 + 策略形态进 P4 机制清单(候选);target 采纳另行立项;
- 任一出口 ⇒ H-P1 结束,链进 nodes-out → P4 proper;无第五出口;
  实测方向、逐类 ρ、幅度全部如实入档。

## 8. 边界与不做什么

- V0 与 P3-A/B/C 冻结零改动;结构策略 = 诊断工具非 target,采纳
  另行立项;C 不因本轮改写身份;
- 生成的方向先验全部来自冻结域定义(拓扑/游走规则),声明为
  generator-derived priors,非经验拟合;方向判错 = L3 如实失败,
  不改向重跑;
- 单拓扑(链 8×4);分枝拓扑显式排除;hot = 阴性对照域;
- S1 结果只归因于冻结拓扑中的位置/深度结构(8 链 × 4 深度),
  不自动升级为一般性"模型层级功能机制";更广功能意义需换拓扑/
  分片/任务域后另轮验证;
- 不反推 Track B / M 链 / P0 系列;P0.2 经济闭合不变。
