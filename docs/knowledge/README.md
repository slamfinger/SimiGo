# 知识索引

本目录只保留由证据提炼出的产品 / 架构知识，不保存研究过程日志，也不替代证据原件。

## 分类

- [Findings](findings/README.md)：由明确证据支持的发现。
- [Principles](principles/README.md)：有适用范围和反例边界的可复用原则。
- [Invariants](invariants/README.md)：经验证、对核心架构有约束力的不变量。
- [Open Problems](open-problems/README.md)：当前仍未关闭的问题。

历史迁移材料与来源说明见 [Research archive](../research/README.md) 和 [Evolution](../evolution/README.md)。不再维护没有实际条目的分类目录。

## 证据规则

知识层级不是措辞强度：Observation → Finding → Principle → Invariant。升级必须能追溯到具体证据、适用范围和反例；目录存在或文档被命名为“原则”不构成验证。
