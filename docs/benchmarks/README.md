# 性能与正确性基准

这里记录 SimiGo 的实机测量、正确性对照和回归数据。

## 原则

Benchmark 是证据，不是架构规则。

一个参数即使在某台机器、某个模型、某个版本上取得最佳结果，也不能直接成为永久配置或核心不变量。

## 建议记录

```text

SimiGo 版本 / Commit

请求数量

正确性结果

TTFT

```

## 与架构的关系

```text
Benchmark
    ↓
Evidence
    ↓
Decision
```

性能数据只能支持决策，不能代替架构边界。
