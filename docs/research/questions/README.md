# Research Questions

这里保存 SimiGo-Lab 的预注册研究问题。

每个问题应明确：

- Research question
- Scope / population
- Existing knowledge
- Unknown
- Independent knowledge channels
- Evidence required
- Experiments
- Acceptance / falsification conditions
- Current conclusion
- Remaining uncertainty

研究问题之间不得通过重新命名同一证据来制造独立性。
