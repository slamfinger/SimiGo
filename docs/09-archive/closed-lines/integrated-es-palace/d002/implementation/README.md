# D-002 preparation-only implementation

Creates one transactionally consistent SQLite snapshot of the read-only PALACE
carrier, derives seven isolated fixture cases from the first seven ordered
snapshot records, maps them to D-001 typed schemas, validates preparation, and
stops. It does not run an experiment or observer campaign.

Forbidden: canonical/PALACE mutation, network, models, semantic search,
embedding traversal, E9, EXP-004, PIR reopening, and equivalence claims.
