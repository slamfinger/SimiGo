```text
PALACE 解决：信息空间
  文件发现 / 内容提炼 / 信息关联 / 变化检测 / 历史判断可审查
  回答 = 「世界里有什么？过去知道什么？」

  PALACE → 提供稳定的信息世界
  SimiGo → 保存人在这个世界中的行动状态
```
