## 1. Research Question（human 原语冻结）

> **如果今天把当前工作停止，明天重新打开，我究竟需要什么，才能
> 真正从这里继续，而不是重新做一遍？**

核心压缩（human 措辞）：

> **停止工作之后，哪些过去发生过的事情必须仍然存在，下一次工作
> 才能不是从头开始？**

## 2. 核心对照（两条件）

```text
条件 A（只有 L0）：
  Corpus-1 原始文件（A×8 + D×6）
  ↓ 重新发现 → 重新比较 → 重新判断 → 才能继续

条件 B（L0 + 当前工作记录）：
  同一 L0 + G1/G2 实际过程产物原样
  ↓ 直接恢复 → 继续下一步
```

## 3. 硬指标：重做量（Redo Cost，human 指定）

不问「能不能继续」，记录：

```text
没有工作记录时，为重新达到 G2 T-3 停止时的工作状态，需要：
  · 重新执行多少步骤
  · 重新读取多少文件（含 cell/文本读取量）
  · 重新做多少判断
```

使「全量计算 → 增量计算」从概念成为可观察的工程事实。

**H-G1-02 材料流向（预登记，判定归结果门）**：重复工作/
信息损失/路径丢失/无法定步 = H-G1-02 的四类合格信号（human
先前裁定）；单纯效率差 = 不升格。本实验产出该判定的实测材料。

## 4. 工作记录原样性保护（human 特别裁定，防污染）

```text
条件 B 使用的工作记录 = G1/G2 执行过程实际产物原样：
  · baseline-inventory.json（Corpus-1 五字段清单）
  · discovery-set.json + corrections（E6 发现集与修正）
  · t1-mapping-results.json（T-1 映射结果）
  · G1 主探针/OQ-B/E6/G2 观察记录文档（在档原样）
❌ 禁止为本次实验新整理任何「漂亮摘要」
❌ 禁止对上述记录做任何增删改（含格式优化）
理由：人为精心整理的摘要会污染实验——G3 的价值恰恰是观察
真实工作过程中自然产生、传统文件检索容易丢掉的东西，哪些在
第二天变得不可替代
```

## 6. 执行阶段（R-1…R-5）

```text
R-1 停止点冻结：
    停止点 = G2 T-3 完成时点；从实际过程记录原样枚举该时点

    重做量对照（A vs B）+ 五项恢复矩阵 + H-G1-02 材料登记
```

## 7. Evidence Grade 与判读纪律

```text
Observation = 恢复矩阵 + 重做量计数（原样）
Inference   = 「X 必须持久化」级结论须四类合格信号之一
              （重复工作/信息损失/路径丢失/无法定步）且替代
              解释排除
Open        = 记录缺口与矛盾（原样登记）
纪律：重做量显著 ≠ 自动升格 H-G1-02——按四类信号归类后判定；
      两结果均有效
```
