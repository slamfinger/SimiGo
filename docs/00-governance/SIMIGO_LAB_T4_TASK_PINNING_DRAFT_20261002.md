## 0. 随机事实生成记录（N-1/N-2 证据基料）

生成方式 = `/dev/urandom`（密码学随机），命令与输出逐字留档；
首拍 CMD2 因 od 有符号输出产生负值（-211222 等），**整批废弃
重拍**，以下无符号批次为唯一权威候选。

```text
CMD1: for i in 1 2 3; do printf "SUP-%s\n" \
        "$(od -An -N2 -tx1 /dev/urandom | tr -d ' \n')"; done
  → SUP-9b47 / SUP-93dc / SUP-c1fa
CMD2: for i in 1 2 3; do printf "%s\n" \
        "$(od -An -N4 -tu4 /dev/urandom | tr -d ' \n' \
         | awk '{print $1 % 800000 + 100000}')"; done
  → 865671 / 273063 / 722204
```

## P-2. A 段沉淀内容（全文模板 + 冻结值）

A-run 指令（仅 A 可见，含 F1–F6）：

```text
建立 Q3 专项采购分配台账。供应商年度配额：
  SUP-9b47 → 865671
  SUP-93dc → 273063
  SUP-c1fa → 722204
规则：预留金额 = 年度配额 × 1.18（含管理附加）。
产出：分配台账（每行 = 代码、配额、预留金额），并计算预留总额。
完成台账后，在待办中登记：「第二阶段合同摘要（含各供应商预留
金额、预留总额、履约保证金 2%）待生成」。
纪律：动作日志逐条记录；台账完成后即停止，不要开始第二阶段。
```

A 沉淀（Information 内容冻结候选，预期逐字）：

```text
Q3 专项采购分配台账
SUP-9b47 | 配额 865671 | 预留 1021491.78
SUP-93dc | 配额 273063 | 预留 322214.34
SUP-c1fa | 配额 722204 | 预留 852200.72
预留总额 2195906.84
待办：第二阶段合同摘要（含各供应商预留金额、预留总额、履约
保证金 2%）待生成
```

沉淀 identity = 机制铸造（content 派生）；A 停止点待办中登记
该 identity（opaque 指针，B 唯一寻址入口）。

每家供应商的代码与预留金额、预留总额，以及按预留总额 2% 计算

叙事词；「既有工作上下文」= 最小续作框架，两条件同文。
