# SimiGo v2.1 Reference App — Architecture Gate Mapping

Status: **Reference implementation / Architecture Gate draft**  
Contract: **Execution State Contract v1.0-amended**  
Scope: no model inference, no MLX/llama UI, no v2.1 GA claim.

## 1. Product boundary

```text
Execution State Graph UI
        ↓
ExecutionStateGraphStore
        ↓
Reference Representation Declaration
        ↓
Atomic durable graph document
```

v2.1 的第一层对象不是 Conversation / Message / Prompt，而是：

```text
ExecutionStateRecord
├── Identity
├── Parent / lineage
├── Position
├── Anchor
├── Continuation
├── Lifecycle
└── durable checkpoint bindings
```

## 2. Contract → App mapping

| Contract obligation | App operation | Current evidence |
|---|---|---|
| create：明确 identity + 初始 position | `create()` | 新建 `S-xxxx`，position 0，空 canonical prefix |
| continue：严格前缀延接 | `continueState(_:input:)` | append token，position +1，anchor/continuation 重算 |
| fork：分叉点两侧 closure 完整，parent 非污染 | `fork(_:)` | child value-copy parent closure；parent 记录不变 |
| save/checkpoint：当前 closure durable 固化 | `save(_:)` | checkpoint 保存同一 semantic closure，不新建 semantic state |
| restore：fail-closed | `restore(_:checkpoint:)` | identity/model/anchor/checksum 全部通过才返回 restored |
| discard：无 ghost continuation | `discard(_:)` | 原子移除 checkpoint binding 并置 discarded |
| release：清空 binding | `release(_:)` | 移除 durable binding，保留 logical state |

## 3. Representation boundary

当前第一阶段使用 `R_Reference_v1`：

```text
Σ_R      ReferenceCheckpointV1
C_R      canonical token-prefix array
Inv_R    anchor hash / record checksum / model identity
Rules_R  ρ_R1 anchor integrity · ρ_R2 prefix extension · ρ_R3 record integrity
```

它用于验证 App 的 Contract-shaped 结构，不是 MLX 或 llama.cpp conformance claim。  
真实 backend 必须后续以独立 Representation Declaration + version-pinned battery 接入。

## 4. Persistence model

持久文件：

```text
~/Library/Application Support/SimiGo/StateGraph/reference-graph-v1.json
```

- 文档记录 contract 和 representation 版本。
- 每次生命周期 transition 先构造 next document，再原子写盘；写盘成功后才更新 UI state。
- 启动时损坏或版本不符即 fail-closed，不自动覆盖旧图。

## 5. Verification

Targeted suite:

```text
SimiGoTests/ExecutionStateGraphTests
```

覆盖：

- create → continue → fork 的 parent 非污染；
- save → continue → restore；
- checkpoint tamper 后 restore fail-closed；
- durable graph 跨 store 实例恢复；
- discard 无 ghost checkpoint；
- release 只清 binding，不废除 logical state。

## 6. Non-claims

本阶段不宣称：

- backend-independent Execution State；
- MLX / llama.cpp conformance；
- production GA；
- universal Execution State theory；
- 任何性能优势。
