# L1 Research State Capsule Index

Status: DERIVED COVERAGE INDEX / NOT AUTHORITATIVE  
Capsule model: L1 = compressed recovery material, below L2 authority and L3
evidence  
Expansion guard: this index does not authorize new capsules or experiments.

Each capsule owns its detailed research question, established/not-established
claims, bounding, dependencies, source documents, evidence, commit, and claim
mapping. This index adds estate-wide coverage: what is covered, how completely,
and whether it is current.

## Coverage legend

```text
COMPLETE NODE   capsule covers its registered bounded node
PARTIAL NODE    useful bounded summary, but the line has more records
HISTORICAL      intentionally retained for provenance
CURRENT         still needed to recover the active route
SUPERSEDED      historical input; later route or ruling changed direction
```

`SUPERSEDED` never rewrites or devalues the capsule's historical evidence.

## Reading rule

For any capsule claim, continue downward to the capsule's cited L2 and L3.
If this index abbreviates or conflicts with a capsule, the capsule wins for its
bounded node. If the capsule conflicts with L2 or Frozen Contracts, L2/Frozen
Contracts win.
