研究问题（human 指定形态冻结）：

> 当变化是在信息工作过程中实际发生时（v1 → 用户/外部修改一个
> cell → v2 → 重新进入），系统能观察到什么？——能否发现变化？
> 能否知道旧状态？能否定位变化？能否继续原来的探索？

## 1. 设置（隔离沙箱，L0 真实原件零触碰）

```text
v1 = 复制 Corpus-1 A 族一件至沙箱（建议：
     2秦沈项目标后预算明细表-1.15局会议修改后.xlsx 工作副本；
     已有内容级事实基线：汇总表结构 + 材料量价样例已知）
建立可发现性 = 五字段基线 + 内容抽样记录（预登记「已发现」清单，
     例如：材料量价 Sheet B17 钢筋 / C17 4200 / D17 元/t——
     以实际 cell 坐标抽样为准，执行时落盘）
外部修改（模拟用户/外部编辑，脚本执行一次）：
     修改一个 cell 的值（例：钢筋单价 4200 → 4500）
     ——不增删 Sheet、不改结构、只改一个值
v2 = 修改后的工作副本
重新进入 = 重新执行可发现性建立 + 内容抽样
```

## 2. 观察格（预登记）

```text
OB-1 变化检测（五字段层）  mtime/size/hash 是否变化？
OB-2 变化定位（内容层）    能否定位到「哪个 cell 改了」？
                          （已知可行工具：cell 级 diff——记录
                          实际操作成本）
OB-3 旧状态知识            预登记的「已发现」记录（4200）在 v2
                          下是否仍可寻？——旧值是否留有任何
                          痕迹（v2 文件内 / 系统任何层）？
                          预登记预期：无痕迹（L0 被覆盖）——
                          若有痕迹 ⇒ 偏离 → 溯源
OB-4 探索继续性            「我刚才看到的东西现在变了吗？」——
                          预登记发现记录 vs v2 现实的矛盾
                          如何被检测/处置；原探索结论
                          （4200 相关比较）是否失效
```
