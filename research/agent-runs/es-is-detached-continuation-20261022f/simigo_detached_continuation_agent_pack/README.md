# SimiGo Detached-Continuation Agent Pack

This pack directs the local agent to implement and run the next core research experiment in native Swift/MLX. It is deliberately not a database anti-rollback/security expansion.

## Start in Qoder / local agent

Open `AGENT_TASK.md` and tell the agent:

> Execute `AGENT_TASK.md` autonomously against the current local working tree. Begin with all specified before-snapshots and source audit before changing anything. Implement native Swift/MLX code, run build and tests, then run the real-model detached-continuation experiment. Do not stop after planning. Do not commit/push. Preserve all existing A–E evidence and unrelated dirty/untracked work. The final deliverable is code plus raw run evidence in the specified external run root.

## Contents

- `AGENT_TASK.md`: implementation requirements, hard boundaries, experiment design and acceptance.
- `experiment_plan.json`: machine-readable phases and conditions.
- `evidence_schema.json`: minimum evidence fields to record per world/condition.
- `workspace_guard.py`: pre/post working-tree snapshot and allowlist verifier.
- `artifact_guard.py`: hashes pre-existing experiment output roots before/after, independently of Git status.
- `validate_plan_pack.py`: validates pack JSON and the required experimental condition set.
