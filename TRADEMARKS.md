# Trademarks and Project Identity

`SimiGo`, the SimiGo logo, and related official-product marks identify the
official SimiGo project and products. They are not licensed under the source
code or documentation licenses.

Forks and compatible implementations may make factually accurate statements
such as:

```text
based on Apache-2.0 SimiGo code
implements the SimiGo Execution State Contract vX
passes the SimiGo conformance battery vX
```

They must not imply official status, endorsement, or affiliation. Compatible
products should use their own product name and clearly identify their relation
to SimiGo.
