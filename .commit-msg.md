Feat: NativeMLX idle lifecycle (Phase 1) — suspend/resume + health-check tuning

Decouple service liveness (isRunning/httpServer) from weight residency
(modelContainer). Suspend after idle timeout releases the model container
and Physical KV revisions while keeping the HTTP server listening; the next
generate() call lazily resumes via ensureLoaded(). checkHealth() treats a
suspended-but-listening server as healthy so it does not trigger a restart.

Service health loop triggers suspendIfIdle for the MLX backend on a 30s
cycle with a 120s idle timeout, independent of the GGUF swap mechanism.
